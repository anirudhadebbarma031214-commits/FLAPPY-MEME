# FLAPPY MEME — India vs USA

An original, lightweight Flappy Bird-inspired browser arcade game with a bright animated canvas, score tracking, mobile touch controls, keyboard support, and optional meme-style speech sounds.

## Play locally
Open `index.html` in a modern browser. No dependencies, build tools, API keys, or server are required.

## Controls
- Click/tap the game or press **Space / Arrow Up** to flap.
- Dodge the pipes and beat your best score.
- Choose India, USA, mixed, or silent sound mode.
- Use the Sound button to mute or unmute.

## Publish with GitHub Pages
1. Open the repository **Settings → Pages**.
2. Under **Build and deployment**, select **Deploy from a branch**.
3. Choose branch **main** and folder **/(root)**, then save.
4. After deployment, the game will be available at the repository's GitHub Pages URL.

Best score is saved in the browser's local storage. Speech availability depends on the browser and device.
